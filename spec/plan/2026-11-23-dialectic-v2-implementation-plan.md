## 0. レビューで一致した事実 (e796c5a)

| # | 事実 | 根拠 (レビュー) |

| F2 | 応答の LLM 障害・空応答は `fail()` = 応答済み・子なしで閉じ、相手の反論が成立して自分の論拠が崩れる | Astra §4 / Fable 1-3 |
| F3 | まとめ文は終了理由によらず「落ち着きました」。集計は refuted 以外を一括で「残った」 | 両者 (P1) |
| F4 | 止揚の入力・批准の分母に崩れた根拠が入る。批准の `preservedIds` は重複を数える | Astra §4 / Fable 4-3 |
| F5 | 結論は rounds 用の `generate_conclusion` を共用し、投票の勝者 + 直近 20 発話を「重視」させる。投票が無いと結論 LLM を呼ばない | 両者 |
| F6 | 投票は決着後に走り、決着・論破・止揚の判定は投票を見ない。使い道は収束信号・結論入力 (有害)・表示だけ | 両者 |
| F7 | 進行役の開幕・指名・まとめは定型文の口語化で、論点あたり 8〜16 回 (進行役モデル)。失敗時は定型文に戻る | Astra §2 / Fable 2-2 |
| F8 | 収束で残りの論点を打ち切ると、未討議の論点が結論にもペーパーにも出ない | 両者 |
| F9 | 遊び手のタイプ (嗜好軸 descriptor) は dialectic の定立・応答 prompt に届かない | 両者 |

## 1. 本 PR の範囲 (1 PR に集約)

順序は Fable 5-3 を採る (版 → 未決 → 告知 → 結論)。

| 段 | 内容 | 主な変更 | 受入 (コードで確かめる) |
|---|---|---|---|
| V0 | **版の記録 (P10)** | `flow.dialectic.version` (既定 `v2`)、`flow_conclusion.engine_version` 列 | 新しい結論行に `v2` が入る |
| V1 | **未決を未決として扱う (P2 + F2)** | `exchange`: 応答障害は `errored` (未決)。`cut`/`errored` を含む根は `unsettled`。`goal`: 崩れた + 未決だけの陣営は論破にしない (結論なし・未決) | 深さ 4/5 どちらでも打ち切りが勝敗を作らない / 応答障害で相手の反論が成立しない |
| V2 | **打ち切りの告知と内訳 (P1)、進行文の定型化 (F7)** | `run_ground_exchange` が終了理由・打ち切り件数・陣営別内訳を返す。開幕・指名・まとめは定型文 (LLM を呼ばない) | 上限時に「一段落」と言わず内訳と応答待ち件数を告げる / 進行役 LLM 呼び出し 0 |
| V3 | **止揚と批准 (P3 の前半 + P7)** | 止揚の入力から崩れた根拠を「前提に使わない」枠へ。`preserves` に崩れた根拠があれば折衷。批准は生存根拠の集合を分母にし ID を重複排除。生存 0 は止揚不可。批准の結果を決着表に写す | 崩れた根拠を preserves に入れた候補は止揚にならない / 重複 ID で過半数を満たせない |
| V4 | **dialectic 専用の結論 (P3 後半 + F5 + F8)** | 決着表 (全予定論点・区分・残った/崩れた/未決の根拠・批准・未討議) をコードで本文に写し、LLM は要約部だけを書く。投票の勝者と直近 20 発話は渡さない。生成条件は「決着が 1 件以上」。要約に失敗しても表だけで concluded | 結論本文に全論点の行がある / 未討議の論点が「未討議」で出る / 投票なしでも結論が出る |
| V5 | **投票を既定 off (F6)** | `flow.dialectic.vote` (既定 false)。off のとき収束信号 (b) は「論点が止揚・論破で決着した」に置き換える。rounds・改善フローの投票は変えない | dialectic で vote LLM が呼ばれない / on なら従来どおり |
| V6 | **応答者の選び方 (P6)** | 応答対象の連鎖でその陣営が直近に発言した人を優先 | 同陣営 2 人のとき元の反論者が続ける |
| V7 | **人物像を発話に載せる (アーキタイプ A1)** | 人物ヘッダを 1 関数にまとめ (定立・応答・批准)、憑依/プール人物の descriptor を載せる | descriptor の無い人は従来どおり / 有る人は定立・応答・批准の prompt に出る |
| V8 | **運用 (P11)** | claude CLI の exit≠0 で stderr が空なら stdout 先頭を error に含める | 単体テスト |
