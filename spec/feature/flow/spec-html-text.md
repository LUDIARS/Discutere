# HTML 仕様書の本文抽出

関連タスク: `actio:7559760d-cc76-4a02-9079-eb202ab08d71`

URL・ローカルファイル・アップロードの HTML は `src/flow/strip-html.ts` の
純粋関数で本文へ変換する。script、style、一般タグの順で半角空白へ置換し、
既存の文字参照の復号と空白の正規化を適用する。script/style の名前は大文字小文字を
区別しない。閉じないブロックは残して一般タグ除去へ回し、末尾の閉じないタグは
文字列として残す。文字参照の復号は Office XML と既存の実装を共有する。

各走査は前方にだけ進み、閉じが見つからない時はその走査を打ち切る。
入力長に対する時間・追加メモリは O(n)。HTML DOM 構築や新規依存は導入しない。
これは既存の本文抽出の互換性を保つ処理であり、HTML サニタイザーとしては使わない。

C-2 stripHtml(html): 整形式HTMLの本文と空白正規化を維持し、256KiB以上の未閉鎖タグを1秒未満で処理する

Augur の計画に沿って、整形式・文字参照・空白・未閉鎖タグの回帰テストを先に記述する。
修正前に256 KiB以上の `<script ` / `<style ` / `<a ` の反復入力が1秒を超えることを
確認し、修正後に同じテストの成功を確認する。検証対象は追加の `strip-html.test.ts` と
既存の `spec-source.test.ts` に限定する。
