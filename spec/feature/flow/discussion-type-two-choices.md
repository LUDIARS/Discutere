# 議論タイプは二択

根拠: neco「壁打ち消して」。企画/議論はプロジェクトなし、改善/議論はプロジェクトあり。

- Discord と Web の選択肢は企画/議論・改善/議論のみ。
- 旧壁打ちメニュー、英語 sparring、設定別名からの新規開始は拒否する。
- フォーラム同期時に旧壁打ち・学習タグを除去し、残るタグの ID とメタデータは保持する。
- 議論適性から壁打ちへ誘導しない。過去の評価に保存された再提案も再表示しない。
- 過去の会話記録は削除しない。内部の旧型は履歴互換のため残るが、新規入口には公開しない。

Cc が企画/議論をコード作業用セッションと誤認してプロジェクトを質問する件は、
Concordia の CC-FORUM-TYPE-01 で対応する。

型・差分の静的確認を実施。セッションからのテスト・再起動は未実施。
