Discutere

ゲームデザインの「意図された体験」と「観測された体験」を弁証法的対話で突き合わせる、 Discord-only の自走議論 ChatBot（コードネーム Discatier）。

Node.js 22+ / TypeScript (ESM) discord.js v14 — Gateway 常時接続 Hono :3100 Kuzu(SQLite) + Event Log Anthropic SDK / Claude CLI / local LLM

Discutere は「遊び（ゲーム）」をテーマに AI ペルソナ同士が自走で議論し、結論・止揚（アウフヘーベン）を生み出す プラットフォームです。人間は Discord のフォーラムや平文チャットで議題を投げるだけ。分類器 → 議論エンジン → ファシリテーターが 自動で議論を立て、進め、まとめます。生み出された議論はすべて 次の議論の学習データとして知識グラフ（KG）に蓄積されます。

役割 — 何をするサービスか

🗣️ 自走議論

賛成派・反対派・意見屋の AI ペルソナが輪番で意見をぶつけ、複数ラウンドで論点を深掘りする。人間発言には最優先で即応。

⚖️ ファシリテーション

論点を絞り、対立を止揚で統合し、収束を促す。収束したら Discord スレッドを lock + archive してまとめを転記。

🧠 学習データ蓄積

全フローの成果物・発話を Kuzu 知識グラフ + コーパスに蓄積。外部の生の声を出所付き・個人仮名で RAG 参照する。

🕸️ 外部クロール

ゲーム攻略 KG クローラと、Steam / YouTube / Reddit 等の外部議論クローラ。議論前に情報密度を評価して自動学習。

📊 可視化 / エクスポート

学習ビュー・議論キュー・経済グラフ・ダッシュボード。議論を Markdown で 1 本にエクスポート。

💾 バックアップ

KG + 全 SQLite を tar.gz 化して S3（Glacier 系）へ。月次自動 + 手動（CLI / slash）。

認証モデル（意図的設計）

Discutere は 半ローカルツール（Discord ギルド内限定の議論 ChatBot）。公開 SaaS ではないため Cernere 認証は使わず、認証を Discord に依存させる。transport は Discord Gateway（WebSocket）常時接続で、 WS 接続自体が bot token 認証。認証境界 = bot token + admin-id allowlist（DISCUTERE_DISCORD_ADMIN_IDS）。 HTTP Interactions Endpoint / Ed25519 署名検証は撤去済み（2026-05-30 WS 再設計）。
