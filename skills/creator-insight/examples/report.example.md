## 1. 人生脚本（アンケート）

- 優位なドライバーは「完全であれ」（3.50）。場面での選択でも5回中3回選ばれている。確度: 高。[lifeScript.drivers]
- 次に「強くあれ」（3.25）。評定だけで、場面での選択とは一致していない。確度: 中。[lifeScript.drivers]
- プロセス脚本は「〜までは」（3.33）。「完全であれ」と対応する。確度: 高。[lifeScript.process]
- 基本的構えは、他者に肯定的。自己は境界で、どちらとも言えない。[lifeScript.position]
- 聞いてみたいこと: 途中のものを人に見せてよいと思えるのは、どのくらい出来たときか。

## 2. 性格（行動スタイル）

- 勤勉性: 高め。報告と、期限のあとの完了報告が集団より多い。確度: 中。[chat.report_rate, chat.deadline_followup_rate, code.test_touch_share]
- 協調性: 高めに見える。他人の質問への回答が多い。ただし異論をほとんど出しておらず、場の圧力の反映かもしれない。確度: 低。[chat.help_giving_rate, chat.disagreement_rate, Q9]
- 外向性: 低め。自分から話を始めることが少なく、やりとりの相手も少ない。読むだけの参加や役割の影響かもしれない。確度: 低。[chat.initiation_rate, chat.partner_breadth]
- 開放性: データ不足。話題の広さと外部リンクは集団内で差が出ず、使える指標がジャンルの広さ1つだけ。

## 3. プレイタイプ

- 遊び手: 「上達」と「競争」が強い。高難度の踏破やタイムを詰める話が、7日にわたって9回。忌避は「反復」（周回への否定的な発言が4回）。確度: 中。[play.player.style.mastery, play.player.style.competitor, Q3, Q7]
- 作り手: 「探索」と「自由度」。4作品中3作品が探索型で、生成まわりのコードを繰り返し作り直している。確度: 中。[play.maker.style.explorer, code.rework_areas]

## 4. 食い違いと問い

- 遊ぶのは上達と競争、作るのは探索。自分が遊んで燃える要素を、作品に入れていないのはなぜか。
- 「強くあれ」が高く、質問・相談は集団より少ない（z=−1.1）。一方で他人の質問にはよく答えている（z=+0.9）。助ける側には回れるが、頼る側には回りにくいのかもしれない。[chat.help_seeking_rate, chat.help_giving_rate]
- 直後の小修正コミット（z=+1.3）と投稿の編集（z=+1.2）が多い。「完全であれ」と合う。途中経過を共有する場面を増やすと楽になるか。[code.fixup_share, chat.edit_rate]
