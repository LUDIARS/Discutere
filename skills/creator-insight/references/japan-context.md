# 日本特化の前提

このスキルは日本語話者と日本の制作現場（学校・スタジオ・サークル）を前提にする。
欧米の研究で使われる指標をそのまま当てると読み違える箇所を、先に固定しておく。
他の言語・地域の対象者には使わない。使うなら、その地域の前提文書を別に作る。

## 1. 言葉づかいは関係で決まる

- 敬体（です・ます）か常体かは、相手との上下と親疎で決まる。丁寧さを性格の指標にしない。
- 相手を「先輩・教員・上長 / 同輩 / 後輩 / 不明」に分け、層ごとに集計する。層の間の差（切り替えの幅）は見てよい。
- クッション言葉（恐縮ですが、お手数ですが、もしよければ）は礼儀の定型。協調性や自信のなさの根拠にしない。
- 「すみません」は謝罪・感謝・呼びかけを兼ねる。謝罪の回数として数えない。
- 謙遜の定型（まだまだです、大したものではないですが）は自己評価の低さを意味しない。

## 2. 公開の場には建前が出る

- 公開チャンネルの発言は、役割としての発言が多い。反対意見が少ないことを「協調的」と読まない。
- 発言せずリアクションだけで同意を示す、読むだけで参加する、は普通の参加の形。発言量の少なさを消極性と決めつけない。
- 発言量は学年・役割・担当で大きく変わる。比較は同じ層の中で行う。

## 3. 自己申告は真ん中と控えめに寄る

- 奇数件法では「どちらともいえない」に集まりやすい。設問は偶数件法（4件法）にする。
- 自分を控えめに評定しやすい。絶対値で読まず、本人の中での相対順位（どの尺度が相対的に高いか）で読む。
- 抽象的な自己評価より、具体的な場面と頻度で聞く。
- 強制選択の設問を混ぜ、評定と選択が一致するかを見る。

## 4. 比べる相手は同じ集団

- 絵文字・顔文字・「w」「草」・「！」の多さは、世代とコミュニティの方言。同じサーバ・同じチームの中での相対位置（z値）だけを使う。
- 欧米の基準値や、ほかのコミュニティの平均と比べない。
- 集団が8人未満なら相対位置を出さず、本人の中での記述にとどめる。

## 5. 属性を推定しない

- 一人称（僕・俺・私・自分・うち）、語尾、方言から、性別・年齢・出身地を推定しない。特徴量にも入れない。
- 活動時間帯（深夜の投稿など）を健康や生活の状態に結びつけない。作業リズムの記述にだけ使う。
- 課金は姿勢（慎重 / 抵抗がない）だけを扱う。金額や家計を推定しない。

## 6. ゲームの語彙は日本の遊び方に合わせる

- 対人で相手を倒す動機を中心に置いた分類は合いにくい。協力・ソロ・収集・育成・周回・推しの比重が大きい。
- 「ガチ勢 / エンジョイ勢」「周回」「ガチャ・天井・無課金・微課金」「推し」「やり込み」「縛りプレイ」「トロコン」などの語を辞書に持つ（`play-type.md`）。
- 実況・配信で見ただけのタイトルは「視聴」として、遊んだタイトルと分けて数える。

## 7. 個人情報の扱い

- 本人の同意と利用目的の特定が前提。目的の外に使わない。
- 要配慮個人情報にあたる事項（病歴、障害、信条など）は、推定も記録もしない。
- 会話相手（本人以外）の発言本文は読まない・残さない。集計に必要なメタ情報（時刻、仮名ID、返信関係）だけを使う。
