# プレイタイプ

遊びの好みを、Voluptas と Discutere が共有する語彙で記述する。新しい類型を作らない。

## 語彙

好みの15軸を使う。正本は Voluptas の `PREFERENCE_AXES`（`preferenceAxisDefinitions.js`）。

| 軸 | 表示名 |
|---|---|
| `mtg.timmy` | 大きな体験 |
| `mtg.johnny` | 独自の工夫 |
| `mtg.spike` | 勝利と最適化 |
| `style.achiever` | 達成 |
| `style.explorer` | 探索 |
| `style.socializer` | 交流 |
| `style.competitor` | 競争 |
| `style.collector` | 収集 |
| `style.narrative` | 物語 |
| `style.relaxation` | くつろぎ |
| `style.mastery` | 上達 |
| `style.onboarding_need` | 丁寧な導入 |
| `style.autonomy` | 自由度 |
| `style.routine_tolerance` | 反復 |
| `style.monetization_sensitivity` | 課金への慎重さ |

分類の12次元（遊び手の型5、遊びの型4、物語の型3）は Voluptas の `hobbyPatternDefinitions.js` が正本。
このスキルでは15軸を主に使い、12次元は Voluptas の分析結果がある場合に引用するだけにする。

## 2つの面を分けて出す

| 面 | 意味 | 主な根拠 |
|---|---|---|
| 遊び手 | 何を好んで遊ぶか | アンケート、プレイ記録、遊んだゲームについての発言 |
| 作り手 | 何を好んで作るか | ポートフォリオ、コードで手をかけている領域、企画の発言 |

2つは一致しないことが多い（遊ぶのは対戦、作るのは探索、など）。
差は欠点ではなく、本人の企画の源を探る問いになる。

## 根拠の強さ

1. 本人が答えたアンケート
2. プレイ記録（所有、プレイ時間）
3. 遊んだゲームについての本人の発言
4. 作ったもの（作り手の面にだけ使う）

上にあるものを優先する。
Voluptas の分析結果がある場合は、それを遊び手の面の第一の根拠とし、このスキルで別のスコアを作り直さない。

## 発言から拾う

ロジックで行う。

1. タイトル名を拾う。遊んだ / 見ただけ（実況・配信） / 名前を出しただけ、を分ける。分けられないものは「言及」として弱く数える。
2. 語彙の一致を軸ごとに数える（下の辞書）。
3. 極性を付ける。一致の前後20字に否定・忌避の語（嫌い、苦手、だるい、面倒、飽きた、やめた、合わない、〜ない）があれば「忌避」として別に数える。好みと忌避を相殺しない。
4. 極性が決められない一致は引用の候補に回し、上限の範囲でLLMが読む。

語が一致しただけでは好みと言えない。
同じ軸で別の日の一致が3回以上あるとき、またはアンケートかプレイ記録の根拠が1つ以上あるときだけ記述する。

## 作ったものから拾う

作り手の面に使う。

- ポートフォリオの各作品のジャンルとメカニクスに、導入先のメカニクス辞書のIDを付ける（辞書は `ADAPTER.md`）。
- コードは、手をかけている領域をパスで分ける（操作感・戦闘 / 生成・レベル / UI / 通信 / ツール / 描画）。コミット数と期間で比重を出す。
- 何度も作り直している所を重く見る。1回で通した所より、本人のこだわりが出る。

## 日本の遊び方に合わせた注意

- 「競争」は対人の勝敗だけでなく、スコア・タイム・ランキング・高難度の踏破を含めて数える。対人戦の語が無いことを競争の低さと読まない。
- 「交流」は協力プレイ、身内でのマルチ、通話しながらのプレイが中心。見知らぬ相手との交流とは分けて考える。
- 「反復」は周回や日課への耐性。周回、作業のように文脈で好みにも忌避にもなる語は、必ず極性を見る。
- 「課金への慎重さ」は姿勢だけ。金額に触れた発言は引用しない。
- 推しやキャラクターへの愛着は「物語」と「収集」の両方に出る。どちらか一方に寄せず、文脈で振り分ける。
- 実況・配信で見ただけのタイトルは「視聴」として分け、遊び手の根拠としては弱く扱う。

## 出し方

- 遊び手・作り手それぞれ、強い軸を上位3つまで、忌避を2つまで。それぞれに根拠IDと確度を付ける。
- 根拠が無い軸は「データ不足」。0点や「好まない」と書かない。
- 遊び手と作り手の差を1〜2行で書き、問いにする。
