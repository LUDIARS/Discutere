# T6: 壁打ちフロー (ユーザターン起点・上限付き)

設計参照: `spec/flow/sparring.md`。依存: **T2, T3**。

## ゴール

ユーザターン起点で、ユーザの不定期発話に対し議論を継続する対話フロー。ラウンド/ターン数の
固定制限なし (暴走ガード上限あり)。コマンド発話で締め・終了する。

## スコープ

### in
0. **入口**: 壁打ちは**テーマ投稿時に議論タイプ「壁打ち」を選択**して入る (T7 dispatch が flow=壁打ち
   で本ドライバを起動)。発話内容からの自動判定はしない。
1. **壁打ちドライバ** (`src/flow/sparring.ts`, FlowDirector を壁打ち用に拡張 or 派生):
   - **起点 = ユーザターン**。ユーザ発話 → 議論側が応答、を繰り返す。
   - ユーザは**不定期発話**でよい (固定ターン待ちをしない)。各ユーザ発話に応答する。
   - **ラウンド/ターン固定制限なし**。ただし `flow.sparringMaxTurns` で**暴走ガード上限**。
   - 応答は議論フローの発話生成 (T2 のペルソナ発話 + ディスカッションペーパー) を流用。
     人間優先即応は既存 `respond-to-human` / `human-*` の考え方を流用。

2. **終了コマンド** (`src/flow/sparring-commands.ts`):
   | ユーザ発話 | 動作 |
   |---|---|
   | **「まとめて」** | そのラウンドを終了 (ファシリテーターがラウンドまとめ → 続行可) |
   | **「おわり」** | 議論を終了し、まとめに入る (= フロー終了、結論ビューで整形) |
   - 検出は文字列一致を基本に、軽いゆらぎ (「まとめてください」等) を許容。判定方式 (classifier か
     文字列一致か) と許容範囲は実装時に決め、指示書末尾に記録。

3. **既存資産流用**:
   - Web チャット (`spec/feature/web-chat.md`, `scene=web:<room>`) の 1 対 1 ポーリング対話が起点に
     近い → 流用候補。

### out
- 議論フロー骨格の再実装 (T2/T3 流用)。正式 WebUI 入口の作り込み (T7)。

## 受け入れ条件 (テスト, MockLLM)
- ユーザ発話起点で応答が返り、ユーザの次発話まで待てる (不定期)。
- `flow.sparringMaxTurns` 到達で安全に打ち切る。
- 「まとめて」でラウンドが締まり続行可能、「おわり」でフロー終了 + 結論まとめが出る。
- コマンドのゆらぎ (「まとめてください」) を拾えることを 1 ケース確認。
